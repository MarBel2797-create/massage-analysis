   Консольное приложение на Python для ведения базы клиентов, учета услуг и анализа ключевых показателей (выручка, средний чек, популярные услуги).

   Функциональность:

- Добавление, редактирование и удаление записей о сеансах.
- Просмотр списка всех клиентов.
- Формирование отчетов: общий, за конкретный месяц.
- Визуализация данных (три графика).
- Сохранение и загрузка данных из CSV-файла.


    Как запустить:
  1. Убедитесь, что у вас установлен Python и библиотеки: 'pip install pandas matplotlib'.
  2. Запустите скрипт: 'python massage.py'.
  3. Следуйте инструкциям в меню программы.

      Технологии
     - Python
     - Pandas
     - Matplotlib
